SHS 2 Mathematics | Counting Techniques

Fundamental Counting Principle

Learn how to determine the total number of possible outcomes when two or more events occur using systematic counting methods.

Course: Mathematics Topic: Counting Techniques Level: SHS 2 Duration: 60 Minutes

Lesson Objectives

Learning Indicators

  • Explain the meaning of the Fundamental Counting Principle.
  • Identify situations where multiplication is used for counting.
  • Determine possible outcomes using the counting principle.
  • Apply the principle to solve real-life problems.

Success Criteria

At the end of this lesson, I can:

  • Explain why multiplication is used in counting.
  • Represent possible outcomes systematically.
  • Calculate the number of possible arrangements.
  • Justify my answers mathematically.

Understanding the Concept

The Fundamental Counting Principle

If one event can occur in m ways and another independent event can occur in n ways, then the two events can occur together in:

Number of outcomes = m × n

Instead of listing every possible outcome, multiplication allows us to count possibilities quickly and efficiently.

Real-Life Applications

Choosing Outfits

Finding possible clothing combinations from different shirts and trousers.

Creating Passwords

Determining how many possible passwords can be created.

Selecting Meals

Finding possible meal choices from different menus.

Worked Examples

Example 1: Clothing Combination

A student has 3 shirts and 2 trousers. How many different outfits are possible?

Number of shirts = 3

Number of trousers = 2

Number of outfits:
3 × 2 = 6

Therefore, 6 different outfits can be created.

Example 2: Meal Selection

A restaurant has 4 drinks and 5 meals. How many possible food choices are available?

Number of drinks = 4

Number of meals = 5

Total outcome : 4 × 5 = 20

Therefore, 20 possible foods can be selected.

Visualizing Possible Outcomes

Tree Diagram

A tree diagram shows each possible choice step by step. It helps us visualize how different choices combine to create outcomes.

Outcome Table

The outcome table organizes all possible combinations from the choices and allows us to count the total number of outcomes.

Finding the Total Number of Outcomes

Number of shirt choices × Number of trouser choices

2 × 2 = 4

Therefore, there are 4 possible outfit combinations.
